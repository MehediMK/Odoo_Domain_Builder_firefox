Syntax guide Operators & value types

AND matches all conditions. OR matches any. NOT negates an entire group. Add groups to combine them.

Lists use JSON input: ["draft", "sent"], [1, 2] or [true, false]. Output uses Python syntax. False / unset emits False, the Odoo unset value.

Use dotted fields such as partner_id.name. Connect to load all fields exposed by your Odoo account, including custom fields. Use Browse fields to select related fields. Dates use YYYY-MM-DD; date/time values are entered in UTC. Relations use record IDs or JSON lists of IDs. Server-specific behavior and record access still depend on Odoo.
